# leadbot

Telegram-бот на aiogram 3 для приёма заявок на разработку ботов: приветствие
с меню, калькулятор примерной стоимости, форма заявки и отзывы с ручной
модерацией. Все данные — в SQLite.

## Структура проекта

- `bot.py` — точка входа: все хендлеры и FSM-сценарии (заявка, отзыв).
- `config.py` — токен, ID админа, вилки цен/сроков (`PRICING`) и типы ботов
  (`BOT_TYPES`) — здесь всё меняется без правки логики.
- `db.py` — SQLite: таблицы `requests` (заявки) и `reviews` (отзывы +
  статус модерации).
- `storage.py` — куда класть файл базы (`leads.db`), см. раздел «Деплой».
- `requirements.txt`, `Dockerfile`, `.env.example` — окружение и запуск.

## Запуск локально

```bash
python3 -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

export BOT_TOKEN="токен_от_BotFather"
python bot.py
```

`ADMIN_ID` уже задан по умолчанию в `config.py` (537259850) — отдельно
задавать не нужно, если это не твой ID. `DATA_DIR` для локального запуска не
нужен — база `leads.db` появится рядом с кодом.

Скопируй `.env.example` в `.env`, если удобнее держать переменные в файле
(бот их сам не подхватывает — грузи через `export $(cat .env | xargs)` или
средствами хостинга, см. ниже).

## Деплой на bothost.ru

1. Залей репозиторий на GitHub.
2. На [bothost.ru](https://bothost.ru/) создай бота, подключи GitHub-репозиторий
   и выбери ветку — деплой будет запускаться на каждый пуш.
3. Главный файл — `bot.py`, рантайм — Python.
4. В переменных окружения панели задай:
   - `BOT_TOKEN` — токен от @BotFather (обязательно)
   - `DATA_DIR=/app/data` — **обязательно**, иначе база `leads.db` будет
     обнуляться при каждом пуше (между деплоями переживает только
     `/app/data`, всё остальное перезаписывается кодом из репозитория)
   - `ADMIN_ID` — только если заявки должны приходить не тебе, а кому-то
     другому

## Как менять цены и типы ботов

Всё — в `config.py`, словари `BOT_TYPES` и `PRICING`. Правишь текст или
цифры, коммитишь, пушишь — новый деплой подхватит изменения.

## Как проверить, что всё работает

- Напиши боту `/start` — должно прийти приветствие с тремя кнопками.
- «Узнать примерную стоимость» → выбери тип → должна показаться вилка
  цены/срока и кнопка «Оставить заявку».
- «Оставить заявку» → пройди все шаги → тебе на `ADMIN_ID` должно прийти
  сообщение со всеми данными заявки, а заявителю — «Спасибо! Свяжусь с вами
  в течение дня.».
- «Отзывы» → без одобренных отзывов покажет заглушку. «Оставить отзыв» →
  напиши текст → превью с кнопками «Отправить»/«Отправить анонимно» → тебе
  придёт заявка на модерацию с кнопками «✅ Одобрить»/«❌ Отклонить». После
  одобрения отзыв появляется в списке «Отзывы» (анонимно, если выбрано так
  при отправке) — тебе в модерации в любом случае виден настоящий автор.

## Особенности

- FSM хранится в памяти (`MemoryStorage`) — после рестарта бота недописанные
  заявки/отзывы теряются, это нормально: пользователь просто начинает заново
  кнопкой из меню.
- Кнопка «✖️ Отмена» работает на любом шаге формы и возвращает в главное меню.
- В `reviews.is_anonymous` хранится только флаг для *публичного* показа —
  `user_id`/`username`/`full_name` реального автора в базе остаются всегда,
  их видно в сообщении модерации.
